# Reminders

The **Reminders** module tracks system-generated notifications and manually set alerts for the purchase management team. Reminders help users keep track of purchase requisitions awaiting approval, pending deliveries, expiring vendor contracts, and follow-ups.

---

## 1. Reminders Dashboard
To view your alerts and notifications, navigate to **Purchase Management** > **Reminders**.

The dashboard displays a tabular list of alerts containing the following details:
*   **Subject / Description**: The core alert message (e.g., pending approvals or deadline alerts).
*   **Date & Time**: When the notification was triggered.
*   **Status**: Indicated by a color dot or label (e.g., *Unread* or *Read*).
*   **Actions**:
    *   **Edit (Pencil Icon)**: Available on unread reminders to modify fields or mark them as read.
    *   **Info (Info Icon)**: Opens a detailed read-only view of a completed or read reminder.

![Reminders List](/img/purchase/reminders/reminders-list.png)

---

## 2. Reading and Actioning Reminders

### Unread Reminders
To read and dismiss/action an unread reminder:
1. Click the **Edit (Pencil Icon)** next to the unread reminder in the list.
2. A modal will open displaying the full alert description, associated links, and notes.
3. In this modal, you can update internal comments or flags.
4. Click **Mark as Read** to archive the reminder or update its status.

![Unread Reminder Action](/img/purchase/reminders/reminder-modal.png)

### Read Reminders
Once a reminder is marked as read:
1. The pencil icon changes to an **Info (Info Icon)**.
2. Clicking the Info icon opens a view-only modal showing the archived reminder content, timestamps, and the name of the user who marked it as read.
