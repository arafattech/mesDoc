# Items Return

This module lets you record and track items returned to the store against an issued Store Requisition (SR).

## View Items Return List
To view the Items Return list:
1. Navigate to **Store Management > SR Management > Items Return**.
2. The list shows Return No, SR No, Department, Items, Return Qty, Return Date, and Status.
3. Use **Search** or the column filter icons to narrow down records.

![Items Return List](/img/store/items-return/items-return-list.png)

## View Return Details
To view or act on a return request:
1. Click the **info** icon in the Actions column of a row.
2. Review the Return No, Department, Issued SR, Return Date, Reason, and the returned Items table.
3. Click **Approve** or **Reject** to process the request, or **Cancel** to close without changes.

![Items Return Details](/img/store/items-return/items-return-detail.png)

## Create a New Items Return
To return items to the store:
1. Click the **New** button on the Items Return page.
2. Select the **Department** and the **Issued SR** the items are being returned against.
3. Set the **Return Date** and add a **Reason**.
4. In the Items table, set the **Return Qty** for each item to return.
5. Click **Submit** to save, or **Cancel** to discard.

![Create Items Return](/img/store/items-return/items-return-add.png)
