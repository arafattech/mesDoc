# Reminders

Set and track follow-up reminders against Material Receipt Records (MRR) that need further attention.

## View Reminders List
To view the Reminders list:
1. Navigate to **Store Management > Reminders**.
2. Use the **All**, **Unread**, and **Read** tabs to filter reminders.
3. The list shows MRR No, Message, Reminder Date, and Read status.

![Reminders List](/img/store/reminders/reminders-list.png)

## Create a New Reminder
To set a new reminder:
1. Click the **New** button.
2. Select the **MRR** and set the **Reminder Date**.
3. Type the **Message** and, optionally, a **Purchase Message**.
4. Click **Submit** to save, or **Cancel** to discard.

![Create Reminder](/img/store/reminders/reminders-add.png)

## View / Action a Reminder
To review a reminder:
1. Click the **pencil (Edit)** icon in the Actions column for an unread reminder, or the **info** icon for one already marked as read.
2. Review the MRR, Reminder Date, Message, Purchase Message, and the related **MRR Log** (received items).
3. On an unread reminder, tick **I have read** to mark it as read.

![View Reminder](/img/store/reminders/reminders-view.png)
